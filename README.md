# Simple Interest Calculator

## Project Description

The Simple Interest Calculator is a Bash-based calculator that computes simple interest using three inputs:

* Principal amount
* Rate of interest
* Time period

## Formula

**Simple Interest = (Principal × Rate × Time) / 100**

## Features

* Accepts principal amount from the user
* Accepts rate of interest from the user
* Accepts time period from the user
* Calculates and displays the simple interest
* Simple and easy-to-use Bash script

## Project File

The main calculator script is:

`simple-interest.sh`

## Example

If:

* Principal = 10000
* Rate = 5%
* Time = 2 years

Then:

**Simple Interest = 1000**
